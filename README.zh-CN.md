# 桌宠待办

[English](README.md) | **简体中文**

基于 Electron 的 Windows 桌面宠物，用于管理待办事项和课程表。宠物常驻桌面，在对话框中按优先级展示未完成任务，并定时提醒护眼、饮水和活动。角色形象可自行绘制并替换。

## 功能

- **任务**：标题与内容、文件链接、图片、优先级（红 / 黄 / 绿）、可选截止日期与时间（24 小时制）。
- **对话框**：按优先级列出任务；点击任务进入详情，亦可在独立窗口中打开。列表收起且仍有未完成事项时，宠物旁保留一条半透明提示。
- **日历**：管理窗口提供完整日历，对话框内提供迷你日历，展示当天的待办与课程。
- **课程表**：支持每周重复的课程，字段包括课名、时段、授课方式（线下 / 线上 / 线上+线下）、教师、地点、学分、学期起止及间隔周数，并同步显示在两个日历中。
- **ICS 导入**（如学校导出的课表）：导入前提供预览；重复的单次事件合并为每周规则，重复项自动跳过；同一科目线上、线下时段重叠时，仅在用户确认后才合并。
- **统计**：课程数、学分、每周学时；线上、线下重叠的时段只计一次。
- **提醒与鼓励**：护眼、饮水、活动提醒，间隔可配置；鼓励语在设定时长后自动消失。
- **宠物窗口**：支持拖拽、缩放、始终置顶，宠物以外区域鼠标穿透；对话框可自动切换到上方或下方，控制按钮自动避开屏幕边缘。
- **迷你收音机**：常驻宠物旁，提供上一首 / 播放暂停 / 下一首、音量减 / 静音 / 音量加，并显示当前曲目（过长时滚动）。支持所有使用 Windows 媒体控制的播放器（如网易云音乐、Spotify、浏览器）。点击 ⏻ 可收起为 📻 图标，也可在设置中隐藏。
- **空闲淡化**：鼠标离开数秒后，对话框与收音机变为半透明，悬停时恢复；可在设置中关闭。
- **主题**：亮色（蓝色线稿风格）与暗色（VS Code 风格），宠物对话框、任务窗口和管理窗口同步切换。

## 安装

从 [Releases](../../releases) 页面下载 `Setup` 安装包并运行。

- 安装程序会为当前用户注册**开机自启**，卸载时一并移除。
- 安装包未经代码签名，Windows SmartScreen 可能给出警告，选择「更多信息 → 仍要运行」即可。
- 用户数据保存在 `%APPDATA%\desktop-pet-todo\data`，升级时保留。

## 自定义角色

通过托盘菜单「打开角色素材文件夹」进入素材目录（安装版为 `%APPDATA%\desktop-pet-todo\pet`，源码运行时为 `assets/pet`），放入背景透明的 PNG 图片：

| 状态 | 文件 | 触发时机 |
| --- | --- | --- |
| 待机 idle | `idle.png` | 默认状态 |
| 说话 talk | `talk.png` | 对话框打开时 |
| 紧急 urgent | `urgent.png` | 存在紧急任务时 |
| 开心 happy | `happy.png` | 完成任务时 |
| 睡觉 sleep | `sleep.png` | 没有任务时 |
| 拖拽 drag | `drag.png` | 被拖动时 |

如需动画，为文件名加上 `_1`、`_2` 等序号（如 `idle_1.png`、`idle_2.png`）。建议使用约 800×800 的正方形画布。素材变更会自动生效，详见 `assets/pet/README.txt`。缺少图片时以 emoji 代替。

## 自定义应用图标

将方形、背景透明的 `icon.png`（建议 512×512，不小于 256×256）放到 `build/icon.png`。托盘、管理窗口和任务窗口会使用该图标；执行 `npm run dist` 后，安装包与 exe 也会使用它。未提供时，程序使用内置绘制的蓝色圆脸图标。

## 从源码运行

需要 Node.js 18 或以上。

```bash
npm install
npm start          # 或双击 启动桌宠.bat
npm run dist       # 在 dist/ 中生成安装包
```

从源码运行时，数据保存在项目的 `data/` 目录中（已加入 .gitignore）。

## 配置

- 提醒与鼓励语文本：[renderer/pet.js](renderer/pet.js)（`CHEER_NORMAL`、`CHEER_URGENT` 以及各提醒的 `texts` 数组）。
- 提醒间隔、对话框显示时长、主题、宠物大小、收音机与空闲淡化开关：在管理窗口的设置中调整。

## 项目结构

```
main.js          Electron 主进程（窗口、托盘、拖拽缩放、数据读写）
preload.js       暴露给页面的安全接口
renderer/        宠物、管理窗口、任务窗口、课程表、ICS 解析、主题
assets/pet/      角色素材
build/           安装脚本（开机自启）与 icon.png
```
