# 桌宠待办

[English](README.md) | **简体中文**

一个 Windows 桌面宠物，帮你记待办事项和课程表。宠物待在桌面上，用对话框按优先级显示未完成的任务，还会提醒你护眼、喝水、起来走动。角色可以自己画，把 PNG 放进去就行。

## 功能

- **任务**：标题和内容、文件链接、图片、优先级（红 / 黄 / 绿）、可选的截止日期和时间（24 小时制）。
- **对话框**：按优先级列出任务。点任务可聚焦查看，也能在独立窗口打开。任务列表收起时，宠物旁边会留一条淡淡的「还有工作没完成哟~」。
- **日历**：管理窗口里有完整日历，对话框里有迷你日历，显示当天的待办和课程。
- **课程表**：每周重复的课程，包含课名、时段、线上 / 线下 / 线上+线下、老师、地点、学分、学期起止和每几周一次。两个日历里都会显示。
- **ICS 导入**（例如学校导出的课表）：导入前预览，重复出现的单次事件合并成每周规则，重复项自动跳过，同一科目线上、线下重叠的记录只有在你选择时才合并。
- **统计**：课程数、学分、每周学时。线上、线下重叠的时段只算一次。
- **提醒与打气**：护眼、喝水、活动提醒，间隔可设；打气话会在设定的时间后消失。
- **宠物窗口**：可拖拽、缩放，始终置顶，宠物以外的区域鼠标可穿透。对话框会自动翻到上方或下方，按钮会避开屏幕边缘。
- **小收音机**：一直显示在宠物旁边。上一首 / 播放暂停 / 下一首、音量减 / 静音 / 音量加，并显示当前歌名（太长会滚动）。网易云、Spotify、浏览器等使用 Windows 媒体控制的播放器都能用。点 ⏻ 可收成 📻 小图标，也可以在设置里隐藏。
- **不用时变淡**：鼠标离开几秒后，对话框和收音机变半透明，悬停时恢复完全显示。可在设置里关闭。
- **主题**：亮色（蓝色线稿风）和暗色（VS Code 风格）。一个设置同时切换宠物对话框、任务窗口和管理窗口。

## 安装

在 [Releases](../../releases) 页面下载 `Setup` 安装包并运行。

- 安装程序会为当前用户设置**开机自启**，卸载时会移除。
- 安装包没有签名，Windows SmartScreen 可能会警告：点「更多信息 → 仍要运行」。
- 数据保存在 `%APPDATA%\desktop-pet-todo\data`，更新不会丢。

## 使用你自己的角色

右键托盘图标，选「打开角色素材文件夹」（安装版是 `%APPDATA%\desktop-pet-todo\pet`，源码运行时是 `assets/pet`），把透明背景的 PNG 放进去：

| 状态 | 文件 | 何时显示 |
| --- | --- | --- |
| 待机 idle | `idle.png` | 默认 |
| 说话 talk | `talk.png` | 对话框打开时 |
| 紧急 urgent | `urgent.png` | 有紧急任务 |
| 开心 happy | `happy.png` | 任务完成时 |
| 睡觉 sleep | `sleep.png` | 没有任务 |
| 拖拽 drag | `drag.png` | 被拖动时 |

要做动画，就加上 `_1`、`_2`……（如 `idle_1.png`、`idle_2.png`）。推荐画布为 800×800 左右的正方形。改动会自动生效，详见 `assets/pet/README.txt`。没有图片时宠物会用 emoji 代替。

## 自定义应用图标

放一张方形、透明背景的 `icon.png`（推荐 512×512，至少 256×256）到 `build/icon.png`。托盘、管理窗口和任务窗口会用它；运行 `npm run dist` 后，安装包和 exe 也会用它。没有这张图时会用程序画的蓝色小圆脸。

## 从源码运行

需要 Node.js 18 以上。

```bash
npm install
npm start          # 或双击 启动桌宠.bat
npm run dist       # 在 dist/ 里生成安装包
```

从源码运行时，数据保存在项目里的 `data/`（已被 git 忽略）。

## 自定义

- 提醒和打气的文字：[renderer/pet.js](renderer/pet.js)（`CHEER_NORMAL`、`CHEER_URGENT` 以及各提醒的 `texts` 数组）。
- 提醒间隔、对话框时长、主题、宠物大小、收音机和变淡的开关：在管理窗口的设置里调整。

## 项目结构

```
main.js          Electron 主进程（窗口、托盘、拖拽缩放、数据读写）
preload.js       暴露给页面的安全接口
renderer/        宠物、管理窗口、任务窗口、课程表、ICS 解析、主题
assets/pet/      角色素材
build/           安装脚本（开机自启）和 icon.png
```
