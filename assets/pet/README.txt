(如果想要替换角色，请先把原有的动作删除或放到别处的文件夹)
(若要自行作画, 推荐画布大小800x900)
把角色图片放在这个文件夹，文件名 = 状态名（小写英文），保存后宠物会自动刷新。(根绝原角色的命名方式)

状态        什么时候出现                         必须？
idle        平时待机（有待办但不紧急）           强烈建议（其他状态缺图时都回退到它）
talk        任务气泡打开时                       可选（缺了就用当前基础状态）
urgent      有高优先级 / 已逾期的待办            可选
sleep       没有任何待办                         可选
happy       刚点了“完成”后 3 秒                  可选
drag        被鼠标拖着走时                       可选

动画：同一状态可放多张，按序号轮播（每 0.5 秒换一帧）：
    idle_1.png  idle_2.png  idle_3.png
只有一张就叫 idle.png。也支持 gif / webp / jpg。

要求：透明背景 PNG；建议所有图片画布尺寸一致、脚底对齐（宠物按底边对齐显示）。
